# AntFund AI · 基金主动销售与持有服务工作台

[在线体验](https://cain0624.github.io/antinsure-ai/)

## 产品定位与业务问题

面向基金销售与客户服务团队的可运行场景原型。投资者常在风险测评、费用比较、净值波动与赎回安排中产生困惑。产品把这些问题组织成“目标与期限 → 有效测评 → 证据解释 → 基金比较 → 自主确认 → 持有陪伴”的完整链路。

首期优先降低信息不完整与规则不清晰造成的流失；不以增加推送或频繁买卖作为价值。保留原五层工作台的视觉和可观测链路，全面替换原保险领域的数据与执行逻辑。

## 核心能力

- 三类模拟画像：初次了解、审慎比较、长期持有。
- 九个可操作事件：基金浏览、测评卡点、模拟测评完成、净值回落、定投扣款失败、赎回咨询、模拟申购确认、停止提醒、人工升级。
- 六个执行器：画像、知识检索、适当性检查、基金比较、话术合成、人工复核。
- 有效风险测评、目标、资金期限、自有资金信息为前置条件；超风险或期限不匹配的产品不进入候选。
- 版本化知识与来源展示；过期资料不参与检索，没有知识依据时澄清或升级，不猜测事实。
- Decimal 计算费用，不预测净值或收益，不提供买卖时机指令。
- 显式模拟申购确认才累计演示 GMV；聊天中表示购买意愿不算成交，重复确认不重复计数。
- 已停止主动提醒或未授权时，行为触发不会推介；用户主动询问仍可解释。

## 五层运行链路与 Harness

| 层 | 实际执行的内容 |
|---|---|
| Observe | 读取模拟画像、授权、行为、短期对话记忆 |
| Plan | 判断测评、费用、比较、波动、赎回、投诉和停止提醒等场景 |
| Harness | Prompt 固定版本/稳定分桶、有限状态、工具白名单与四道闸 |
| Act | 执行六个有界任务，保存输入与工具结果 |
| Reflect | 保存 Trace、当前运行指标、失败标签与归因线索 |

工具权限在调用时检查；无自动交易工具。历史 Trace 提供当时输入、输出与步骤快照，快照回看不冒充重新调用模型。所有推理为确定性演示，不声称接入真实大模型、向量库、NLI 模型或投顾服务。

## 基金四道闸

1. **G1 数字与费用**：生成中的费率、金额、期限须有依据，禁止编造数字。
2. **G2 证据与版本**：产品事实无有效依据时阻断；检索先过滤过期和未审批资料。
3. **G3 宣传用语**：阻断绝对化宣传及无依据排名。
4. **G4 适当性与风险边界**：阻断收益承诺、借贷投资与绕过测评；高风险升级人工。

规则检测是可执行基线，并非生产级语义合规判定；否定式风险提示做了专门回归，复杂引用、隐喻与上下文仍需人工抽检及语义评测。

## 指标与效果衡量

业务北极星设计为 **AI 辅助链路的净申购 GMV**：归因窗口内实际确认的申购金额扣除撤单等，真实归因窗口与口径须上线前对齐。不能以聊天意向、点击或模型生成次数代替交易。观察30日持有、赎回、投诉、适当性异常与停止提醒等护栏，防止短期冲量。

此演示未接入订单或真实用户数据，看板只统计当前浏览器运行的会话、候选、转人工、合规检查和模拟确认。模拟 GMV 每次确认使用虚构 10,000 元金额，不表示真实增长、净流入或历史项目成果。

## 评测与 Loop

页面执行100条真实规则回归：60条风险/数字样本、20条安全表达、10条风险匹配、5条无证据阻断、5条费用计算。包含措辞变体，不等于100个独立场景，也不等于真实会话效果评测。

业务评测还需补齐意图识别、证据引用、信息完整度、候选适配、主动触达误扰、端到端任务完成与跨轮对话测试；以真实脱敏会话建立独立测试集，标注预期动作、依据、风险等级和人工标准。Badcase先归因，再审批知识/策略变更，重新跑固定回归后灰度验证。此版本展示闭环入口，不声称已自动学习或完成线上实验。

## 运行与验证

零构建 HTML/CSS/JS；Python标准库业务逻辑通过 Pyodide 在浏览器执行。无需 API KEY，首次需要下载 Python 运行时。无账户、支付、申购或赎回服务连接。

```sh
python3 -m http.server 8895
python3 tests/check_fund.py
```

浏览器访问 http://localhost:8895/。选择画像并触发基金浏览，可查看候选、知识依据、适当性及 Trace。未测评画像不能得到候选；点击模拟完成测评后才解锁符合范围的候选。风险压测与回归按钮均运行实际规则。

## 依据与边界

[证监会《公开募集证券投资基金销售机构监督管理办法》](https://www.csrc.gov.cn/csrc/c106256/c1653806/content.shtml)作为适当性与销售宣传边界参考。真实销售必须对接持牌机构流程及当前有效资料；本项目所有基金、风险映射、画像与费用均为虚构演示，不构成真实基金推介或投资建议。
